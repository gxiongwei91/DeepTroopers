## 1. 依据与已确认范围

用户指定参考任务：[搜寻深岩银河职业技能](codex://threads/01a18163-64ab-79c0-a894-8108e35dd1b4)。先读取其中职业与武器两轮问答，后补读补给、救援、胜负撤离，共五轮；这是用户指定的设计参考，没有重新核验其所有外部维基内容与当前游戏版本。

参考中的核心结构为职业专属武器、固定移动 / 支援工具、职业投掷物，以及独立的通用特长系统。用户已确认首版采用：

- 枪手、钻机手两个职业，允许重复选职。
- 每职业固定 1 主武器、1 副武器、1 投掷物，以及 2 种固定职业工具；任务中只能切换已携带装备。
- 关闭所有友军伤害，包括子弹、喷火、投掷物、动力钻相关攻击与遥控炸药，不设置炸药例外。
- 固定洞穴，指定岩壁与矿石采用不规则局部破坏；规则见 [细碎破坏 v0.3](%E6%8E%98%E5%9C%B0%E6%BD%9C%E5%85%B5_%E7%BB%86%E7%A2%8E%E7%A0%B4%E5%9D%8F%E8%A7%84%E5%88%99_v0.3.md)，不引入全地图任意地形挖掘。
- 首版单人房间界面与完整任务循环，不补 AI；UE 原生联网、独立服务端、多人同步与重连全部后置。

首版“规则端”指同进程的子游戏会话 / 规则对象，不指额外服务器，也不替换大厅全局 GameMode。本游戏接入现有大厅工程，沿用其公共框架；下文多人乘索、队友保护、共同钻孔、救援、断线与复制是后续扩展规则，不作为首版实现或验收门槛。

参考中提及的多武器自选、武器解锁、升级模组、超频和通用特长，均不因本次引用自动进入首版。具体枪械、投掷物和下文数值为首版建议，并非声称已复制或验证原作机制。

## 2. 目标体验与装备清单

枪手为队伍创造持续输出与安全作业的窗口；钻机手处理近处虫群并缩短通行路线。地图主路线应允许任意合法职业组合完成任务，工具创造效率和战术优势。该通路原则是为兼容“允许重复选职”提出的设计建议。

| 槽位 | 枪手建议配装 | 钻机手建议配装 |
| --- | --- | --- |
| 主武器 | 多管机枪：中距离持续射击，连续射击积累热量 | 喷火器：近距离范围持续伤害与短时灼烧 |
| 副武器 | 重型左轮：低射速、单发精确伤害 | 半自动手枪：补足远距离与零散目标处理 |
| 投掷物 | 黏性手雷：附着敌人或岩石后延时爆炸 | 冲击斧：投掷伤害，未命中敌人的斧可回收 |
| 通行工具 | 滑索发射器：建立全队可用的固定滑索 | 动力钻：持续破坏指定岩壁，打开预制捷径 |
| 支援工具 | 护盾发生器：提供短时团队保护区域 | 遥控炸药：范围清怪，并破坏指定岩壁 |
| 通用工具 | 矿镐、照明棒 | 矿镐、照明棒 |

首版建议采用一个固定装备数据资产配置各职业，而不是把工具写死在角色类中。预留装备编号与职业限制字段，未来扩充武器时复用相同装备槽。

## 3. 公共操作与状态规则

以下均为实现前的建议规则。

- 同时只使用一个手持装备；射击、采矿、钻孔、放置、救援和领取补给互斥。切换装备取消未完成的持续动作，已产生的有效进度保留与否由对应交互规则明确。
- 手机横屏布局：左侧移动，右侧滑动转镜头；主动作按钮执行当前装备动作。装备切换通过紧凑选择栏或轮盘完成，避免把全部装备各做一个常驻大按钮。
- 投掷物使用独立快捷操作；照明棒为通用快捷操作。首次快捷投掷会结束正在进行的持续动作。
- 瞄准部署工具时显示落点、长度或作用范围预览；预览有效不代表最终部署必定成功，规则端在提交时仍检查位置、距离、资源与角色状态。
- 首版立即播放预览、射击与操作反馈；物资扣除、命中、部署物生成、岩壁破坏由本地规则端决定，界面不自行改库存。后续联网时改由服务端决定并复制状态。
- 持续动作有开始、维持与结束状态；取消、倒地、切换装备、暂停会结束动作。后续联网还需在断线或输入有效期超时时结束，防止缺少松手消息后持续操作。
- 请求失败不消耗弹药 / 工具次数，反馈应指明“距离过远”“位置不适合”“资源不足”“正在执行其他动作”等可理解的原因。合法射击 / 投掷未命中仍按正常使用消耗资源，不能把未命中视为请求失败。
- 敌我判定统一使用队伍关系；所有已确认的友军伤害为 0。友军不会成为辅助瞄准目标，不触发黏性手雷附着与冲击斧的敌人命中状态。
- Demo 默认同时关闭自身武器 / 爆炸伤害，已与核心规则一致；它属于补齐的默认规则，不声称用户曾单独选择自身伤害选项。

## 4. 枪手工具

### 4.1 滑索发射器

- 触发：选中滑索工具，瞄准可锚定岩面，确认放置。起点由角色脚边的有效地面锚点确定，终点为瞄准命中点。
- 检查：两端有支撑，长度与坡度符合配置，索道不穿过封闭岩壁，玩家与终点可达位置有足够净空；已达到部署上限时拒绝放置。
- 成功：消耗 1 发滑索弹，生成带稳定编号的滑索；所有队员可在两端交互上下索，沿索双向移动。
- 移动：首版由本人按固定速度乘坐，跳离后恢复普通移动；坠落 / 越界交由生存系统处理。后续允许多人同时乘坐，彼此不推挤，再单独验证网络移动。
- 存续：部署成功的滑索持续到本局结束，建议首版不提供主动拆除，避免队友乘坐时被删除。
- 边界：瞄准岩壁已被队友破坏、角色已倒地或资源不足时拒绝部署；重复请求不能额外生成或扣费。两端离地无安全出口时禁止部署。
- 岩壁限制：将会消失的可破坏岩壁表面不作为滑索锚点，避免岩壁消失后留下悬空锚点。

### 4.2 护盾发生器

- 触发：在近距离有效地面选择位置并投放。成功后消耗 1 次充能，启动持续时间与冷却。
- 作用对象：保护范围内的全部队员；不要求队员属于枪手职业。
- 基础效果：阻挡敌方直射弹道，使普通近战虫避让保护区域，并加快内部角色个人护盾恢复。核心规则默认护盾上限 50，罩内立即以每秒 25 点恢复；首版保护本人，后续扩为所有队员。
- 释放时已有普通虫在范围内：施加驱离行为；不能仅放一个碰撞球把单位困在罩内。若敌人暂时无法离开，驱离期间停止其普通近战攻击。
- 边界：护罩不视为地板，不阻止坠落，不治疗生命，也不提供自动复活。多罩重叠时个人护盾恢复效果取最高值，不叠加倍数。
- 每名枪手最多存在一个有效护罩；同一团队可存在多个枪手的护罩。生效期间禁止再次部署本人的护罩。
- 首版无需建立“所有攻击绝对无敌”的规则；新增敌人攻击类型时必须显式声明护罩能否阻挡。

## 5. 钻机手工具

### 5.1 动力钻

- 触发：选中动力钻，对准 240 厘米内可破坏岩壁或矿点持续使用。
- 作用：按命中块及半径内邻块扣耐久，有效作业扣燃料；中断保留损伤。单块归零后只移除该块模型和碰撞，需形成足够净空才能通行。
- 掉落：岩壁产土块，矿点产可拾取矿块，不销毁矿物；空气和不可破坏边界不消耗钻燃料。
- 首版不增加动力钻敌人近战、体温或过热系统；详细参数、公式及边界见细碎破坏 v0.3。

### 5.2 遥控炸药

- 触发：选中炸药工具，确认有效落点后放置，消耗 1 包；经过短暂起爆准备后可以遥控引爆。
- 同一玩家最多保留 1 包未引爆炸药；再次主操作用于引爆，不能无意中放下第二包。
- 作用对象：范围内敌人、可破坏岩壁与矿点。矿点只转为掉落矿块；已掉落矿物、运输机器人和队友不受爆破伤害。
- 地形处理：按碎块距离和遮挡计算局部破坏，远处未打掉的岩体保留；不再一击整墙消失。主路线保持可通行。
- 回收：拥有者在近距离交互可回收未引爆炸药，恢复 1 包库存；库存已满时拒绝回收并保留炸药。回收、引爆与销毁互斥，一包炸药最多产生一次返还或一次爆炸。
- 首版倒地：立即锁定失败，不再接受起爆操作；重开清理原炸药，不自动引爆。后续断线时炸药保留，60 秒内重连恢复所有权与状态，超时离队清除未爆炸药，不返还为公共物资。
- 队友反馈：显示所有者、作用范围和是否已起爆准备完成。因为友伤关闭，范围标识用于判断敌人和岩壁是否覆盖，不显示会误导队友的友伤警告。

## 6. 武器与投掷物的首版行为建议

| 装备 | 主要规则 | 首版边界 |
| --- | --- | --- |
| 多管机枪 | 按住连续射击；消耗弹药并增加热量；停止射击时降温；过热后短暂禁射 | 不加入改装、穿透与多种弹药；热量与禁射结束由本局规则端确认 |
| 重型左轮 | 单发射击，有限弹巢，手动或空仓换弹 | 换弹可被切换装备 / 倒地取消；只在换弹完成时转移实际弹药 |
| 黏性手雷 | 投掷后附着敌人或世界；引信到期爆炸 | 首版只做附着与爆炸，暂不增加恐惧效果；不粘附队友；可局部破坏岩壁和矿石并掉落碎块 |
| 喷火器 | 有限油箱与储备燃料；按住造成近距离持续伤害，并刷新短时灼烧 | 不加入完整温度系统与地面持续火墙；灼烧叠加建议只刷新时间，不按帧新增无限层 |
| 半自动手枪 | 每次触发单发；有限弹匣，需要换弹 | 不与喷火共享弹药；不加入武器模组 |
| 冲击斧 | 命中敌人造成一次伤害；命中地形后留下可回收斧 | 未命中敌人才可由原拥有者回收；库存满则保留场上斧；一把斧仅可返还一次；后续队友遮挡不算命中敌人 |

伤害、射速与弹药容量需结合敌人生命、虫潮数量和补给方式配置，本轮不把未知敌人数值反推为确定的武器平衡方案。

以下全部是用于首次白盒测试的假设参数，不是参考游戏原值，也不是最终平衡结论。单位使用秒、米、次数及燃料点；进入 UE 时统一将米换算为厘米。

| 字段 | 类型 / 单位 | 初值 | 建议配置范围与约束 |
| --- | --- | --- | --- |
| ZiplineMaxLength | 浮点 / 米 | 30 | 5–50，最短长度另设为 2 米 |
| ZiplineMaxSlope | 浮点 / 度 | 35 | 0–60，取水平夹角绝对值 |
| ZiplineRideSpeed | 浮点 / 米每秒 | 4 | 1–8 |

| ShieldMaxCharges | 整数 / 次 | 3 | 1–6 |
| DrillReach | 浮点 / 米 | 2 | 0.5–3 |
| DrillMaxFuel | 浮点 / 燃料点 | 100 | 20–200 |
| DrillFuelPerSecond | 浮点 / 燃料点每秒 | 10 | 大于 0 |
| DrillWorkPerSecond | 浮点 / 标准工作量每秒 | 20 | 大于 0 |
| StandardWallWork | 旧整墙工作量 | 100 | v0.2 废止消费，资产兼容保留；改用 WallCellHealth |
| SatchelMaxCharges | 整数 / 包 | 2 | 1–4 |
| SatchelArmTime | 浮点 / 秒 | 0.8 | 0.2–2 |
| SatchelRadius | 浮点 / 米 | 5 | 2–8 |
| SatchelPeakDamage | 整数 / 伤害点 | 200 | 大于 0；需与敌人生命一起校准 |
| FriendlyDamageMultiplier | 浮点 / 比例 | 0 | 首版固定为 0，不能被单件武器配置覆盖 |

钻孔计算：更新时长为 Δt 秒，剩余燃料 F 点，燃料速率 c 点 / 秒，工作速率 w 单位 / 秒，直接命中碎块剩余耐久 W_left，则有效时间 `t = min(Δt, F / c, W_left / w)`；扣除 c × t 燃料，对命中块与半径内邻块造成 w × t 伤害。c、w 必须大于 0；其他量非负。保留浮点，UI 显示再取整。最后一刻只扣完成所需燃料；后续多人按服务端稳定顺序处理，完成后的请求不再扣费。

2026-10-29：旧整墙 100 工作量不再消费。当前单块岩壁耐久 30、钻伤害 20/秒；独立钻碎一块 1.5 秒、15 燃料，半径内邻块同时受损。完整公式及每块判定见细碎破坏 v0.3。

炸药伤害建议：对有爆炸视线的敌人，距离中心 d 米、半径 R 米、峰值 D 点时，伤害 = floor(D × max(0, 1 − d / R))。R 必须大于 0，d 不小于 0；友军直接取 0。距离取爆心至目标伤害判定点，距离恰为 R 时伤害为 0。岩壁破坏使用独立的有效目标与爆破范围判断，不把实体伤害值当作矿物收益。

示例：D=200、R=5 时，敌人距离 2 米，伤害为 floor(200×0.6)=120；若同位置目标是队友，则伤害为 0。该示例仅验证计算规则，不证明武器强度合适。

补给已与核心规则一致：80 硝石呼叫 4 份；每份整数工具增加 `ceil(最大容量 × 0.5)`，燃料增加最大容量的 50%，均不超过上限。补给不清除冷却 / 热量、不刷新已部署物。先补给至满后不能再靠回收炸药 / 斧突破容量。

## 8. 资源与配置需求

- 每职业需要角色区分标识、主 / 副武器与工具占位模型、握持 / 射击 / 投掷 / 作业基础动作，以及可区分的音效与反馈。
- 公共需要矿镐与照明棒、准星、装备切换、弹药 / 热量 / 燃料 / 充能提示、落点预览、交互进度和失败原因提示。
- 特殊对象需要滑索两端与索线、护罩效果、可破坏岩壁的完整 / 作业 / 开口状态、炸药包、可回收冲击斧。
- 装备配置至少包含 EquipmentId、ClassId、SlotType、ActionType、资源类型、容量、持续 / 冷却、射程 / 半径、目标过滤与表现资源引用。字段采用稳定编号与枚举，避免用显示中文名称作业务主键。
- 岩壁与矿点使用确定性形状种子、每块耐久、累计破碎产矿及局部凸碰撞；当前运行时参数见细碎破坏 v0.3。多人稳定编号与状态复制后置。

## 9. 最小操作案例与验收

首版案例：单人选择枪手，放置滑索缩短往返，采矿时遇敌则停止作业并射击，受伤后使用护罩与补给恢复。重开选择钻机手，用喷火器清怪、动力钻打开捷径；燃料不足时改用炸药或沿主路线撤离。两种职业分别完成完整任务。

以下表内“两人 / 多人 / 队友 / 重连”相关项是后续联机验收；首版仅执行单人、状态、资源、通路与重复触发检查。

| 验收项 | 预期结果 |
| --- | --- |
| 2 名枪手或 2 名钻机手进入地图 | 主路线与任务矿均可抵达，不因缺少另一职业被卡住 |
| 滑索落点超距、穿墙、锚在可消失岩壁上 | 提示原因，不生成滑索、不扣次数 |
| 两人同时乘坐同一滑索 | 两端交互与沿索移动稳定，彼此不推落 |
| 两个护罩重叠 | 保护状态一致，恢复效果不成倍叠加 |
| 多人共同钻一面岩壁 | 共享进度，只完成一次破坏；开口与可走通路对所有客户端一致 |
| 钻头对准矿脉或不可破坏墙壁 | 矿脉局部破碎并产矿；不可破坏边界不消耗燃料 |
| 炸药回收与起爆请求几乎同时到达 | 仅一个结果生效，不出现既返还又爆炸 |
| 枪弹、喷火、手雷、炸药覆盖队友 | 队友伤害均为 0，不应用灼烧等持续伤害 |
| 冲击斧重复拾取或重连后再次拾取 | 同一斧至多返还一次，库存不超过上限 |
| 持续钻孔或射击中断线 | 服务端及时停止动作，重连不自动恢复按住状态 |
| 遥控炸药放置后重连 | 保留剩余库存与原炸药状态，不额外生成一包 |

规则已与核心文档的单人首版、补给、生命 / 护盾、自身伤害和倒地失败处理对齐。当前只完成文档与公式检查；未编码、运行、联机或试玩。后续仍需试玩校准武器伤害、弹药和工具参数。
