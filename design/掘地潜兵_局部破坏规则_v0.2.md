# 掘地潜兵：岩壁与矿石局部破坏 v0.2

> 本版保留作历史记录。当前分块、枪械特性和产矿累计规则以 [细碎破坏 v0.3](%E6%8E%98%E5%9C%B0%E6%BD%9C%E5%85%B5_%E7%BB%86%E7%A2%8E%E7%A0%B4%E5%9D%8F%E8%A7%84%E5%88%99_v0.3.md) 为准。

更新：2026-10-29。依据本轮用户要求，替代旧版“矿镐整点采矿、动力钻/炸药整墙开门”的限制。目标是让玩家能瞄准局部破坏、看到真实缺口，并从掉落中获取矿物。

## 范围与状态

- 当前地图两面可破坏岩壁及全部晶矿、硝石接入统一破坏。洞穴地板、天花板、外侧边界及固定承重岩体保留，属于本轮实现边界，不是全地图体素挖掘。
- 岩壁与矿点均由确定性生成的不规则凸多面体拼合；不同节点的形状不同。当前每面墙 30 块，每个矿点 6 块。初始外形也做不规则削角。
- 命中哪块，只降低该块耐久；耐久归零后，该块网格和碰撞立即移除，相邻块保留。缺口大小由实际打掉的部位决定，开出足够宽高才能通行。
- 半途松手、换装备后保留已造成的伤害。停止射击不会自动完成整墙破坏。当前残余结构固定保留，不模拟承重倒塌、裂纹传播或无限细分。

## 操作与伤害

| 手段 | 当前作用 | 消耗与边界 |
| --- | --- | --- |
| 机枪、左轮、手枪 | 子弹命中块承受武器伤害 × 枪械破坏倍率 | 沿用弹药、射速、热量和换弹；空枪不破坏 |
| 喷火器 | 瞄准、射程内的岩矿块承受持续伤害 | 暂时允许破坏，后续按武器类型细分；不给矿物附加灼烧收益 |
| 矿镐 `[3]` | 240 厘米内，按住左键重复敲击命中块 | 不耗弹药；每次默认 18 伤害，间隔 MiningTime / 6 秒 |
| 动力钻 `[4]` | 钻机手近距离作业；命中块与破坏半径内相邻块受损 | 有效作业扣燃料，空钻不扣；钻矿同样掉落矿块 |
| 遥控炸药、黏性手雷 | 爆炸范围内按块距离衰减破坏 | 已掉落矿块免伤，不烧毁任务资源；其他完整岩体遮挡爆炸 |
| 冲击斧 | 命中岩矿块造成 110 破坏伤害 | 命中可破坏对象消耗该斧；未命中有效对象落地仍可回收 |

矿镐和枪械通常影响一块；动力钻和爆炸影响局部多块。滑索仍不能锚定会被破坏的岩矿。所有友伤、自伤保持关闭。

## 碎块与拾取

- 岩壁块脱落后生成同形缩小的土块，抛出、旋转、受重力下落并与场景碰撞。土块不挡角色、不伤人，落地累计 8 秒清理；最多保留 64 块，超过时回收最旧土块。
- 用户原句“土块散落在地小时”按“落地后短时间消失”实施，可通过 DebrisLifetime 调整。
- 矿块脱落后变为对应颜色的不规则晶矿块/硝石块，落地后靠近自动拾取；不自动过期、不进入土块回收上限。
- 拾取条件：已经落稳，生成至少 0.35 秒，距角色中心小于 190 厘米且无遮挡。不能隔墙吸矿；高处尚未落地的矿块不会被吸取。
- 背包满则保留在地面并提示；容量只够一部分时只取可装数量，余量留存。晶矿、硝石各自容量仍为 40。
- 如果支撑矿块的表面后来被破坏，矿块继续掉落。异常跌出地图时移回相邻安全路线节点，避免任务矿丢失。
- 暂停冻结破坏、碎块运动及清理计时；重开重新生成完整岩矿，清除上局所有碎块；离开子游戏统一清理。

## 参数与资源守恒

参数位于现有 `DA_DT_Settings` 的 Destruction 分类。新增字段缺省采用 C++ 默认，不覆盖资产原有其他数值。以下为首轮可调值，未作为平衡结论。

| 字段 | 默认值 | 单位/范围 |
| --- | --- | --- |
| WallCellHealth | 30 | 每块耐久，大于 0 |
| OreCellHealth | 18 | 每块耐久，大于 0 |
| WeaponTerrainScale | 1 | 枪械破坏倍率，大于 0；未来可换成按枪械配置 |
| DrillRadius | 145 | 厘米，大于 0 |
| DrillWorkRate | 20 | 每秒破坏伤害，大于 0 |
| DrillFuelRate | 10 | 每秒燃料点，大于 0 |
| DebrisLifetime | 8 | 落地累计秒数，大于 0 |
| DebrisCap | 64 | 土块数量，1–128 |

旧 WallWork 字段为已有资产兼容保留，不再作为整面墙的破坏进度。

单块命中后耐久 `H' = max(0, H − D)`；伤害不溢出到下一块。默认机枪每发 12 伤害，一块墙需 3 发、矿需 2 发；40 伤害副武器可击碎一块。

动力钻有效时间 `t = max(0, min(Δt, F/c, H/w))`：F 为燃料，c 为燃料速率，H 为直接命中块剩余耐久，w 为伤害速率；扣 `c×t`，每个有效块承受 `w×t`。默认单块墙独立受钻 1.5 秒，消耗 15 燃料点；周围块同时受损，不能把此值直接当作整条通道成本。

爆炸对岩矿块的伤害 `D = Peak × max(0, 1 − d/R)`，使用浮点，不取整；d 为爆心到块中心距离，R 为半径。敌人伤害仍沿用既有向下取整规则。

矿量分配：矿点总量 Q、实际块数 N；第 i 块（从 0 编号）获得 `floor(Q/N) + (i < Q mod N ? 1 : 0)`。10 单位分为 6 块，即 `2+2+2+2+1+1=10`。碎块成功生成后才扣原矿量，同一块最多生成一次。全图仍为 300 晶矿、240 硝石；目标仍为交存 200 晶矿。地面矿、背包矿、已交存及已花费矿的合计守恒。

## 反馈与验收

命中岩矿时显示黄色准星反馈及“岩矿受损”；击碎时显示“碎块脱落”，配碎屑火花。与敌人的命中、护甲和击杀区分，不增加击杀数或敌人伤害统计。

示例：枪手用机枪对准岩壁下方，三发击碎一块；附近继续点射扩出能容纳人物的缺口并实际穿过。对晶矿开火，部分矿体留在原位、矿块滚落，走近获得对应数量。背包满后继续打矿，剩余矿块留在地面，交存后回来拾取。

验收覆盖：四种主副枪械；近距离矿镐和动力钻；局部爆炸；未打掉部分仍阻挡、已开洞角色可通过；非致死及重复命中；矿量守恒、满包/部分拾取、落地/遮挡；暂停、碎土回收、两职业重开；实际画面检查。自动化、真实渲染和人工手感结论在运行与验收文档分别记录。

后续扩展：按武器类别配置破坏倍率、半径、穿透与材质克制；提高碎块密度或接入更连续的几何破坏；落地音效、粉尘与正式岩矿材质；联网同步及手机性能专项。均不在本次直接追加。
