# 《掘地潜兵》战斗伤害飘字与弱点暴击表现 v0.1

日期：2026-10-29。用途：程序、美术、UI、音效与测试协作。适配手机横屏，首轮在 UE 编辑器验证。本文为新增表现与规则设计，**尚未接入游戏运行代码**。

本轮修订：按用户最新决定，剔除护甲减伤、暴击击杀专属表现和连射合并。连射时每次有效伤害独立飘字，多条数字同时叠出，并在命中位置附近适度散开。本文继续原路径维护，替代上一版同名文档的对应规则。

## 1. 目标与确认状态

玩家应在一次命中后迅速判断“有没有造成伤害、伤害多少、是否命中弱点”。连射时多条数字接连弹出、同时上浮，以密集反馈增强爽快感；通过近距离错位让最新数字可读，保留敌人轮廓和下一次瞄准位置。

| 状态 | 内容 |
| --- | --- |
| 用户已确认 | 命中怪物有效弱点部位会暴击；暂按 **2 倍**制作示例，倍率保留可调。 |
| 用户本轮调整 | 当前方案仅保留普通、弱点暴击、持续伤害三类数字；逐次独立显示、可同时叠出，密集处小幅散开；不累加成总数。 |
| 已有实现，经源码核对 | 旧代码仍有重甲正面减伤及其准星；尚无弱点增伤和伤害飘字。本轮只改文档与示意，正式接入此方案时需同步移除旧减伤分支与提示。 |
| 本文首轮建议 | 不增加随机暴击；直接且能定位部位的命中参与弱点暴击；数字颜色、大小、时序、散开幅度、数量限制及音效按下文执行。参数待试玩微调。 |
| 范围 | 玩家对敌人造成的普通、暴击和持续伤害。致命伤沿用对应数字样式；击杀统计、死亡动作和既有基础击杀确认仍由原系统负责。岩矿沿用独立方角反馈。 |

规则关系：[核心规则](%E6%8E%98%E5%9C%B0%E6%BD%9C%E5%85%B5_DEMO%E6%A0%B8%E5%BF%83%E8%A7%84%E5%88%99_v0.1.md)、[十字准心表现](%E6%8E%98%E5%9C%B0%E6%BD%9C%E5%85%B5_%E5%8D%81%E5%AD%97%E5%87%86%E5%BF%83%E8%A1%A8%E7%8E%B0.md)、[圆背啃咬虫基础动作](%E6%8E%98%E5%9C%B0%E6%BD%9C%E5%85%B5_%E5%9C%86%E8%83%8C%E5%95%83%E5%92%AC%E8%99%AB%E5%9F%BA%E7%A1%80%E5%8A%A8%E4%BD%9C_v0.1.md)、[细碎破坏规则](%E6%8E%98%E5%9C%B0%E6%BD%9C%E5%85%B5_%E7%BB%86%E7%A2%8E%E7%A0%B4%E5%9D%8F%E8%A7%84%E5%88%99_v0.3.md)。旧文档中“本版无弱点倍率”描述原有实现，本文提出下一步新增需求，不代表倍率已经生效。

## 2. 弱点暴击的判定

### 2.1 有效弱点命中

一次伤害必须同时满足：目标仍存活且可受伤；真实攻击路径命中目标；攻击能提供有效部位命中结果；首个阻挡命中的部位被敌人配置标为启用的弱点。满足即必定暴击，无额外概率掷骰。

- 单纯将准心放在发光部位上不触发暴击。镜头看到弱点、枪口被岩壁挡住时，不对墙后目标产生数字或暴击。
- 先击中普通躯体再指向其后的尾囊，按普通伤害结算。射线必须真正到达弱点；不因为弱点离准心近而改写命中部位。
- 同一次直接命中只结算一次。弱点与普通碰撞交界以最终阻挡命中归属为准；不同时生成普通和暴击两次伤害。
- 弱点命中使用弱点系数 2；不再额外乘一次“暴击 2 倍”形成 4 倍。首版暴击来源就是弱点。
- 本版部位系数只区分普通与弱点；外壳仍可阻挡射线，但不再附加减伤系数。
- 无部位、部位未配置、弱点禁用或灰盒回退缺弱点时，按普通伤害结算，不推断为暴击。美术发光颜色本身不参与数值判定。

### 2.2 当前敌人的接入边界

| 对象 | 可核实的现状 | 本文接入要求 |
| --- | --- | --- |
| 圆背啃咬虫 | 动画路径使用 `AnimatedCreature` 骨骼网格；现有测试检查尾部射线返回 `BoneName=tail`。静态回退保留 `TailSac` 组件。 | 动画路径将有效尾囊碰撞／`tail` 部位映射为弱点；静态路径映射 `TailSac`。不能仅凭命中 `AnimatedCreature` 就算暴击，也不能只检查已经隐藏的静态尾囊。逐姿势复核碰撞范围不能覆盖背甲。 |
| 重甲虫 | 旧实现按方向减伤；核心规则提出背部弱点。 | 按本版方案普通外壳受正常伤害；需要独立、可见的背部弱点及对应碰撞后才能暴击。不能把所有背面命中自动算作弱点。 |

| 来源 | 飘字 | 弱点暴击建议 |
| --- | --- | --- |
| 机枪、左轮、手枪的直接命中 | 每次有效伤害进入飘字事件 | 使用真实命中部位，命中有效弱点必暴击。 |
| 冲击斧、矿镐直接打敌人 | 有效伤害进入飘字事件 | 必须补传真实部位命中结果后，按同一规则暴击；现有仅传目标的调用不足以判定。 |

| 燃烧后续伤害 | 小号“灼烧”数字 | 不继承点燃时的暴击状态，不反复触发暴击火花／音效。 |

## 3. 数字口径与数值示例

本节为建议的表现口径。伤害结算完成后发布一次结果，飘字不得自己重新计算倍率或扣血。

设基础有效伤害为 B，距离／范围等既有修正乘积为 F；部位系数 Z 为普通 1、弱点 M（本次示例 M=2，建议可调范围 1.1–5.0）。F 不含本轮剔除的护甲减伤。

`结算伤害 D = max(0, B × F × Z)`

`实际扣血 A = min(受伤前生命 H, D)`，`受伤后生命 = max(0, H − A)`。

飘字显示 D，以便残血目标仍能传达武器和暴击威力；结算统计累计 A，与现有 `TotalDamage` 的不计过量伤害口径一致。两者必须分字段，不能用飘字数累计战斗统计。已有爆炸伤害若先向下取整，传入的是该结算结果，显示层不改变既有取整顺序。

| 操作案例 | 结算／显示 | 实际扣血及反馈 |
| --- | --- | --- |
| 机枪 12 点，命中普通部位，目标血量充足 | `12` | 扣 12；白色普通数字。 |
| 机枪 12 点，命中启用尾囊 | `12×2=24`，显示 `24`＋“暴击” | 扣 24；金色大字与弱点暴击反馈。 |
| 同枪命中重甲虫普通外壳 | `12` | 按本版方案扣 12，白色数字。 |
| 左轮 40 点命中弱点，目标剩余 10 点生命 | `80`＋“暴击” | 只扣 10、统计加 10、击杀加 1；数字与非致命暴击一致。 |
| 喷火连续两次各 4.5 点，间隔 0.1 秒 | 先后弹出 `4.5`、`4.5` | 两次分别结算、独立飘出；不显示汇总 9。 |
| 机枪在 0.00／0.085／0.17 秒各造成 12 点伤害 | 三条 `12` 同时在场，位置小幅错开 | 不显示 24、36 或“合计 N 次”；每条对应其自身的一次伤害。 |

显示格式统一：`D≥10` 显示四舍五入整数（正数 `floor(D+0.5)`）；`0.1≤D<10` 四舍五入到 1 位小数并去掉末尾 `.0`；`0<D<0.1` 显示 `<0.1`，不将真实小伤害写成 0；`D≤0` 不生成数字。每次独立格式化；已出现的数字不被后续伤害改写。首版不缩写 K／M，不显示负号，不滚动逐个补数字。

## 4. 飘字视觉样式

以下为 1280×720 设计画布的逻辑 UI 单位，交付到 UE 时由现有 HUD DPI 体系统一换算。数字采用清晰的半粗等宽数字风格，不用手写体和难辨认的斜体；支持中文标识。不同状态同时依靠字号、文字和动效区分。

| 类型 | 内容示例 | 颜色建议（sRGB） | 字号／描边 | 动效与寿命 |
| --- | --- | --- | --- | --- |
| 普通伤害 | `12` | 暖白 `#F4F7FA` | 数字 28；深色描边 2 | 轻弹后向上 44；0.65 秒。 |
| 弱点暴击 | `24`，上方“暴击” | 明金 `#FFD85E` | 数字 40；标签 16；描边 3 | 明显放大后回落，向上 64；0.85 秒。 |
| 喷火／灼烧 | `4.5`＋“燃烧”或 `5`＋“灼烧” | 浅橙 `#FFBF91` | 数字 22；标签 14；描边 2 | 每跳独立浮起，向上 32；0.70 秒。 |

致命伤沿用普通／暴击／持续伤害各自样式、大小和寿命，不增加击杀文字、第二份数字或终结动画。暴击始终保持金色和“暴击”标签，命中弱点造成死亡也执行同一规则。

描边使用近黑 `#111821`、不透明度约 90%；可加 1–2 单位短阴影，不铺大面积背板。阴暗洞穴、火焰和明亮弱点三种背景均需检查。数字不跟随相机远近无限变大，也不随敌人缩放。

### 4.1 关键帧

| 阶段 | 普通 | 暴击 |
| --- | --- | --- |
| 出现 | 0–0.06 秒，缩放 0.9→1.1，不透明度 0→1 | 0–0.07 秒，缩放 0.85→1.35，不透明度 0→1 |
| 收束 | 至 0.14 秒，缩放回 1.0 | 至 0.18 秒，缩放回 1.0 |
| 阅读 | 至 0.42 秒，保持清晰、继续缓慢上浮 | 至 0.58 秒，保持清晰、继续上浮 |
| 退出 | 0.42–0.65 秒淡出 | 0.58–0.85 秒淡出 |

每次独立播放弹出与消失，前一条不等待下一条，也不被重置。位移用缓出曲线，按第 5 节在局部扇形内分散。减弱动态效果时保留出生点错位，取消缩放弹跳和横向运动，数字仍逐次出现。

### 4.2 位置、层级和手机横屏

- 出生点取真实命中位置，向上偏移约 24 个屏幕 UI 单位，并避开当前弱点轮廓；无直接命中点的范围／持续伤害取目标上胸或可见身体中心。
- 保存世界命中点快照并逐帧投影；漂移叠加在屏幕空间。数字不绑定死亡后的 Actor，不随高速移动的敌人拖走，也不粘在屏幕固定坐标伪装成其他目标伤害。
- 准心中心半径 40 单位为保留区：新数字矩形与其相交时向侧上方移开，以文字实际包围框计算，不能只判断锚点。
- 右侧动作区、左侧摇杆区、装备栏和任务文字同为避让区。数字之间允许适度叠压；出生阶段优先让新数字可读，不要求所有数字排成互不相交的列表。散开范围到达上限后不继续向其他敌人区域挤。
- 从画面外或被场景挡住的伤害点不新建飘字；已出现数字的世界锚点被遮挡或离屏后，在 0.10 秒内淡出。不钉在屏幕边缘提示墙后目标；透明的命中火花不当作遮挡物。
- 绘制顺序：场景与敌人＜飘字＜准心及交互／操作 HUD＜暂停和结算。飘字全部不接收点击，不阻挡移动、瞄准、开火或触控。
- 在 16:9 和较长横屏比例检查安全区／刘海适配。小窗口先将局部数字簇整体移入安全区、裁减出生候选位置；极端饱和再回收旧字。标签实际显示高度不低于 14 屏幕像素，保留逐次出现的节奏。首版不宣称已通过手机真机验收。

## 5. 连射叠出与适度散开

### 5.1 一次伤害一个数字

每次有效伤害立即生成独立数字，不做时间窗合并、不改写已存在数字、不追加“合计”计数。喷火直接伤害、灼烧每跳和同帧多目标伤害也逐次处理；重复送达的同一事件只显示一次。

同目标的数字可以同时存活、局部叠压，形成连续输出的数字簇。新一条不等待旧一条播完，不因已有普通／暴击数字而吞掉正常射速下的后续数字。

### 5.2 出生错位与上浮轨迹

以下初始参数使用同一套 UI 单位，所有候选位置先满足第 4.2 节的准心／HUD 安全区。

1. 以命中点投影向上 24 单位为数字簇基点，按事件序号轮换五个近邻偏移：`(-24,-4)、(0,-12)、(24,-4)、(-12,6)、(12,6)`。屏幕坐标向右／向下为正。每次允许确定性的 ±4 单位微扰，不每帧重抽位置。
2. 基础横向偏移上限 32。当前目标活跃数字数 n 超过 6 时，散开上限 `R=min(56,32+4×max(0,n−6))`；只是逐渐扩大局部数字簇，不重新排版旧字，不把数字撒到全屏。
3. 按候选点预测出生后 0.10 秒的放大包围框，与同目标最近 0.12 秒的新数字比较。优先选择重叠最少的位置；默认新数字可被覆盖面积不超过自身的 25%，目标是让最新数字主体清楚。最多尝试 10 个候选（五个基点及向上再错开 12 单位的五个位置）。
4. 若都超过建议重叠量，仍选重叠最少且满足 HUD 安全区的位置立即弹出，保持射击节奏；25% 是布局目标，不是延迟或丢弃伤害数字的门槛。允许新旧字短时交叠，不要求每条四周都留空。
5. 出生后主要向上漂移，普通 44、暴击 64、持续 32；允许 ±6 的位移差。横向分量依据出生侧向外延伸，新增位移不超过 16，完整轨迹离基点横向不超过 72。先决定轨迹再播放，运行中不使用互相推挤造成抖动。
6. 新数字绘制在旧数字上方；出生后的暴击数字可获得 0.12 秒前景强调，之后恢复按新旧顺序。旧字继续自身淡出，不因后续命中反复恢复到最亮。相邻目标分别维护数字簇，候选点不得越入另一目标的中心区域。

示例：机枪每 0.085 秒一发，普通数字寿命 0.65 秒，持续命中时同屏约有 `ceil(0.65/0.085)=8` 条独立普通数字；全弱点命中时约有 `ceil(0.85/0.085)=10` 条。表现应是同一局部连续叠出的数字流，不是三个固定槽位轮流替换。

### 5.3 数量上限与生命周期

- 建议每目标上限 **12 条**、全屏上限 **64 条**，包含淡出中的数字；满足当前机枪正常连射，两个上限可调。这些是原型预算，不等于真机性能达标。
- 达到上限时优先回收已经进入淡出阶段的最旧数字；否则回收年龄≥0.20秒的最旧数字，给新事件留位。极端情况下全部不足0.20秒，则回收最旧一条。出生0.12秒内的暴击尽量最后回收。回收不产生汇总数，也不改变真实伤害和统计。
- 一帧超限时按事件时间／序号稳定处理，优先保留最近的输出反馈；需要记录饱和次数供性能与可读性调参。正常单目标机枪连射不应触发回收上限。
- 目标切换后旧目标数字按自身寿命播完，位置保留对应命中点快照；致命伤只新增对应普通／暴击数字，已经存在的数字不被死亡立即清空。尸体不产生新伤害数字。
- 暂停隐藏并冻结计时、位置和出生序号；继续后接续。换枪不清除既有数字。准备、死亡结算、重开、切换子游戏和退出时清空数字、位置缓存和事件去重记录。

## 6. 暴击的组合反馈

所有反馈由一次确认伤害驱动。数字不合并；音效和局部材质强调允许限频，防止密集声音与闪光盖过战斗。

| 通道 | 弱点暴击 | 连射与致命伤处理 |
| --- | --- | --- |
| 准心 | 保留固定中心点与四向短线；增加金色双段斜角和“弱点暴击”，0.28 秒。 | 连续弱点命中刷新该提示；致命伤沿用既有基础击杀确认，不增加暴击击杀组合态。击杀确认期间不被普通／暴击／岩矿提示覆盖；独立暴击数字仍照常出现。 |

## 7. 程序接入建议与配置

以下名称是建议接口／字段，均未创建。击杀事件继续由原战斗系统消费，数字层不增加击杀样式字段。继续沿用现有 C++ 会话、UMG 和原生配置资产，不另建一套战斗真值。

流程：真实命中→识别命中部位→计算并应用一次伤害→输出结果事件→准心／飘字／材质／音效分别消费。

| 建议事件字段 | 用途与边界 |
| --- | --- |
| `MissionId / EventId / TargetId / SourceId` | 按局和伤害事件去重；一次攻击可产生多个目标结果，但每目标结算事件 ID 唯一。不能拿同一发攻击 ID 把爆炸其他目标误删。 |
| `DamageKind / WeaponId / WeakpointId` | 区分直接、喷火、灼烧、爆炸；选择数字样式，暴击必须有有效部位结果。 |
| `ResolvedDamage / AppliedDamage` | 分别供飘字和实际扣血／统计消费；防止过量伤害统计虚高。 |
| `bCritical` | 由结算层确定，决定普通／暴击样式；不从全局最后命中状态推断。 |
| `TargetSequence` | 每目标单调递增序号，选择稳定的出生偏移与轨迹；不能影响伤害。 |
| `HitWorldPosition / HitNormal / GameTime` | 世界锚点快照、局部特效朝向和暂停一致的计时；不能依赖已经销毁的目标才能播放。 |

现有消费者注意：`ADTSession::HitEnemy` 目前只设置一个全局最后命中反馈，不能用该值为所有敌人的飘字着色；需要逐事件结果。喷火提供的表现命中点没有可信部位；斧／矿镐现有调用需要补传接触信息。`DTReticleWidget` 当前用数字范围识别岩矿类型，增加暴击种类时应改为显式类型判断，避免把新暴击枚举当作岩矿方角。

建议在 `DA_DT_Settings` 增加 `DamageFeedback` 表现分类；弱点倍率与部位映射属于战斗配置，不能藏在 UI 动画中。敌人未来拥有独立定义资产时将映射归入其定义，本次不创建多份并行数据源。

| 可调项 | 首轮建议值 | 合法范围／说明 |
| --- | --- | --- |
| `WeakpointDamageMultiplier` | 2.0 | 1.1–5.0，有限；用户确认示例值，后续可调。 |
| `WeakpointBindings` | 圆背尾囊／tail；静态 TailSac 回退 | 唯一部位 ID，绑定存在的碰撞组件或骨骼；禁止把整只骨骼组件都判为弱点。 |
| `NormalFontSize / CriticalFontSize / MinorFontSize` | 28／40／22 | 18–48／28–64／18–36 UI 单位；暴击至少为普通的 1.25 倍。 |
| `NormalLifetime / CriticalLifetime / DotLifetime` | 0.65／0.85／0.70 | 0.3–1.5 秒；出现、阅读、退出阶段之和必须等于总时长。 |
| `MaxPerTarget / MaxOnScreen` | 12／64 | 整数 10–20／32–96，局部上限≤全局上限。 |
| `SpawnSpreadBase / SpawnSpreadMax / TrajectoryXLimit` | 32／56／72 | UI 单位；16–40／40–72／56–96，三者严格递增。 |

| `CritVisualInterval / CritAudioInterval` | 0.08／0.10 | 0.04–0.30 秒；仅限强调效果，不节流真实伤害。 |

同样的范围检查应在编辑器校验和运行加载时生效，拒绝 NaN／无穷／非法枚举、重复部位绑定与空部位引用。首版使用预分配飘字对象池／统一绘制层；数字不单独生成带碰撞的世界 Actor。文本更新和遮挡检测按活跃项处理；真机开销需后测，不能用数量上限代替性能证明。
