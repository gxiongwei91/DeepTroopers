## 目标与样式

目标：玩家连续射击时能持续追踪目标，并区分成功发射、有效命中、护甲减伤、击杀、岩矿破坏和枪口受阻。

- 基础样式：固定中心点＋上下左右四根短线，青白色，黑色描边。
- 中心点始终位于屏幕中心，不随开火、命中、装填而移动或被替换。
- 开火动画作用于四向短线；命中标记使用斜角；岩矿结果使用方角。各层独立。
- 准心按现有 HUD 的 DPI 适配绘制，不依赖字体中“+”或“×”的字形尺寸。
- 当前枪械没有动态散布、举枪瞄准或镜头后坐规则。本轮跳动和外扩仅表达开火节奏，不承诺弹道范围，也不改变伤害、射速或命中率。

## 表现规则

| 触发 | 表现 | 消失 / 恢复规则 |
| --- | --- | --- |
| 普通持枪 | 固定中心点与四向短线 | 持续显示 |
| 成功发射 | 短线瞬时外跳，默认 0.10 秒回收 | 仅在实际扣弹发射后触发；打空和向掩体开枪也会出现 |
| 连续发射 | 每次发射累积外扩，归一化每次增加 0.22，上限 1 | 最后一枪跳动结束后，按默认 0.35 秒从满外扩线性回收 |
| 普通有效命中 | 斜角短线标记，青白色，“命中” | 沿用 0.22 秒；最后 0.08 秒淡出 |
| 护甲减伤 | 橙黄色斜角标记，增加端部横线，“护甲减伤” | 沿用 0.22 秒；不等同破甲或零伤害 |
| 确认击杀 | 橙红色加长斜角及第二段短线，“击杀” | 沿用 0.40 秒；后续普通命中和岩矿反馈不降低其优先级 |
| 岩矿受损 | 橙黄色短方角标记，“岩矿受损” | 沿用岩矿系统的 0.22 秒 |
| 碎块脱落 | 橙黄色长方角标记，“碎块脱落” | 沿用岩矿系统的 0.22 秒；不计作敌人击杀 |
| 枪口路径受阻 | 右侧阻挡符号＋“枪口受阻”，中心点保留 | 实际枪口到瞄准点路径恢复后清除；仍允许沿现有规则向墙射击 |
| 弹匣空、有备弹 | 外框淡化，“空仓 · 按 R 装填” | 装填开始后切换到装填状态；保留现有空仓自动装填 |
| 弹药耗尽 | 外框淡化，“弹药耗尽 · 需要补给” | 补给或切换武器后按实际库存更新 |
| 装填中 | 外框淡化，装填百分比与短进度条 | 现有 1.8 秒装填完成后恢复；切枪按原规则取消装填 |
| 机枪热量增加 | 准心下方短热量条 | 跟随实际热量；副武器与工具不显示机枪热量 |
| 机枪过热锁定 | 外框淡化，“过热 · 冷却中”与冷却进度 | 对齐现有 2 秒发射锁；切枪后隐藏，切回仍在锁定期则恢复提示 |
| 矿镐、动力钻、工具、补给预览 | 保留基础十字，清除枪械开火累积与热量 / 弹匣提示 | 按当前工具及现有交互进度显示 |
| 暂停 / 准备 / 结算 | 隐藏准心与近准心提示 | 暂停冻结反馈计时，继续后恢复；重开、结算、退出清理 |

现有命中火花、敌人闪色、弹药与伤害计算、岩矿掉落、装备切换规则继续沿用。枪械调试弹道线遇到遮挡时终止于碰撞点，避免画面上看起来穿过墙体。

## 信息叠加

1. 开火、命中、限制状态各有独立数据来源。按住开火但处于射击间隔、换弹、空仓或过热锁定时，不新增开火脉冲。
2. 命中标记播放期间仍保留中心定位点和四向短线。
3. 击杀标记不被普通命中、护甲或岩矿结果立即覆盖。持续喷火沿用现有准心命中提示的限频刷新；此处只指准心表现，不合并伤害结算或伤害数字。后续灼烧不伪装成一次枪械命中。护甲提示为待删除的旧实现，见文首修订。
4. 枪口遮挡与装填 / 空仓 / 过热可以同时出现；枪口受阻不等于禁止扣扳机。
5. 命中结果文字、武器状态文字和交互进度分开排列，避免覆盖同一位置。
6. 非敌人可破坏岩矿使用方角；普通场景弹着、空枪、无效伤害不新增敌人命中标记。

## 调参入口

继续使用 `/Game/Games/DeepTroopers/Data/DA_DT_Settings`，新增 `Crosshair` 分类。旧资产缺少的新字段沿用 C++ 默认值，无需重命名或重新生成资源，不涉及存档迁移。

| 配置字段 | 默认值 | 合法范围 | 单位 / 含义 |
| --- | --- | --- | --- |
| CrosshairGap | 7 | 2–20 | UI 单位，中心到短线内端的距离 |
| CrosshairLength | 8 | 3–20 | UI 单位，每根短线长度 |
| CrosshairThickness | 2 | 1–4 | UI 单位，前景线宽；另有描边 |
| CrosshairKick | 4 | 0–12 | UI 单位，单发外跳幅度 |
| CrosshairBloom | 6 | 0–16 | UI 单位，连射累积的最大额外间距 |
| CrosshairKickTime | 0.10 | 0.04–0.30 | 秒，单发跳动持续时间 |
| CrosshairRecovery | 0.35 | 0.10–2.00 | 秒，满累积量完全回收时间 |

间距公式：`实际间距 = 基础间距 + 单发幅度 × 单发剩余比例 + 连射幅度 × 连射累积比例`。两个比例均限制在 0–1。非枪械只使用基础间距。

示例：默认配置、单发比例 1、累积比例 0.22 时，间距为 `7 + 4 × 1 + 6 × 0.22 = 12.32` UI 单位。连续射击的最大间距为 `7 + 4 + 6 = 17`。位置和时间保留浮点插值，装填文字按百分比四舍五入显示；不改变实际装填完成时机。

参数是本轮初始表现值，须经正常速度试玩调整。编辑器限制与运行时校验保持一致，拒绝越界、非有限值及非法零时长。

## 验收方法

- 正常射击：枪手主副武器、钻机手主副武器成功发射时均有开火跳动；空枪不报命中；连续射击外扩有上限，停火恢复。
- 结果区分：普通命中、护甲减伤、击杀、岩矿受损与碎块脱落可辨；中心点始终可用。
- 限制状态：空弹匣与无备弹提示不同；装填完成、过热锁定结束和切枪后提示正确更新。
- 越肩遮挡：镜头能看到目标但枪口被墙挡住时，提前显示阻挡；射击不伤到墙后目标，弹道线不穿过障碍。
- 生命周期：暂停冻结、继续恢复；准备、死亡结算、重开、退出不保留过期反馈。
- 最终画面：真实渲染 PIE 中检查线段对齐、命中时中心可见、中文提示和层级；手感与手机可读性分别记录，不用代码测试替代。

自动检查、真实运行和人工试玩的实际完成情况以运行验收记录为准。
