# 《掘地潜兵》基地到洞穴全流程 v0.1

> 2026-11-03 地图更新：不制作 Soul: Cave 固定复刻关卡；每局随机生成不同的沙盒房间网络，Soul: Cave 不再作为地图接入依赖。以下早期 L 形三房间与 S 房描述仅作历史记录。基地接单、同一飞船、交存、撤离和返航规则保留。

## 目标

本流程以可行走的基地和洞穴为主，通过角色、设备、任务板、运输机器人和飞船等场景实体推进玩法。HUD只补充目标、数值、方向和结果，不代替场景交互。

当前入口是独立远征地图。正式场景与角色美术暂不作为功能验收前提，设备可使用引擎基础网格组合。

## 一轮流程

| 阶段 | 玩家操作 | 场景反馈与规则 |
| --- | --- | --- |
| 基地整备 | 在基地自由移动；靠近四职业中的一个职业位按 E 选择职业；可用主 / 副武器射击靶场训练靶 | 四职业均可选，展示各自固定配置。训练靶显示无限生命，命中会反馈但不会被击杀；练习射击不消耗本局弹药。当前不允许在洞穴中换职业。 |
| 接受任务 | 靠近任务简报台按 E | 接受单人采矿任务；出发时生成本局随机房间网、资源与一套随机虫潮编排，并保证一个固定 Boss 房。主目标为交存 200 晶矿。 |
| 基地补给 | 靠近无限整备库按 E，可重复使用 | 每次恢复生命、护盾、主副弹药、弹匣、投掷物、工具、支援装置、钻机燃料和照明弹；不扣资源、不限次数。 |
| 登舱出发 | 已接受任务后走入基地出发舱 | 当前单人 Demo 中玩家进入舱体后，舱门关闭并启动出发转场；转场结束后同一飞船 Actor 到达洞穴，生成本轮洞穴与角色。 |
| 洞穴探索 | 走出降落舱，探索随机连接并开采 | 玩家开采晶矿、拾取矿块并交存至运输机器人；硝石用于补给。携带量与交存量分开统计。 |
| 虫潮 | 按既有波次规则战斗与继续作业 | 虫潮在探索、采集及撤离阶段均可发生；警报、敌人、设备提示与 HUD 共同反馈。主目标完成后不要求先清空敌人。 |
| 自动返航/定时返场 | 交存 200 晶矿后自动启动返航；未完成时地图时间到 10:00 撤离船自动返场 | 目标完成后的航行时间白盒初值 60 秒；撤离船抵达后自动开放登舱等待区。 |
| 登舱与离舱 | 玩家返回撤离船并进入舱内安全区；不需要按撤离按钮 | 全体玩家登舱后自动起飞；舱内且 200 晶矿目标完成判成功。船抵达后虫潮继续加压，直到全体登舱或玩家死亡。 |
| 返程结算 | 舱门关闭并返航 | 成功结果和本局统计在返航转场途中显示；失败分支在飞船离洞表现中显示原因，随后返回基地出生点。不能用结算按钮提前中断返程。 |
| 回到基地 | 继续走动、重新整备并接受任务 | 同一飞船 Actor 返回基地，玩家在指定出生点重生并恢复整套装备。下一轮需重新在任务简报台接受任务、再走入出发舱；不会自动开局。 |

## 状态与实现边界

- 远征阶段由 `EDTFlowStage` 管理：基地、出发转场、洞穴、成功返航和失败返航；采矿 / 虫潮 / 撤离仍由既有 `EDTPhase` 负责。
- 基地与洞穴在同一运行 World 中切换运行对象；出发舱 Actor 在基地、洞穴和返程中保留同一对象身份，返程完成后重新成为基地中的可交互设备。
- 进入洞穴或返程时清理上一阶段的角色、矿物、敌人、补给和导航对象；单局资源与统计不作为永久成长保存。
- 地图计时到 10:00 触发计划返场；交存目标达成时自动提前返航，白盒航行 60 秒。船抵达后不设自动离场倒计时；全体登舱或玩家死亡锁定结果。
- 暂停、离开子游戏等公共流程仍由现有宿主与 DeepTroopers 会话处理；本流程不实现大厅、账号或匹配。

## 场景 UI 约束

- 基地设备以准星指向、靠近提示、实体灯色 / 标签和按 E 交互为主；任务板显示关卡与目标摘要，整备库反馈恢复完成。
- 同一飞船/落地仓按计划或目标完成事件自动返回本局随机撤离房。HUD显示预计到达时间；抵达后显示增援压力和登舱提示。
- 洞穴沿用已有采矿 HUD、交互进度、装备栏、波次提示和撤离方向；不添加重复的全屏任务菜单。
- 当前为单人本地 Demo。多人规则中“所有当前玩家均登舱才提前起飞、滞留成员分别结算”保留为后续联机阶段；多人实体、同步与分别结算尚未实现。

## 验收用例

1. 通过 GameMain 进入远征入口，玩家出生于可行走基地，职业位、任务板、整备库与飞船均可接近。
2. 在基地切换职业；整备库反复使用后全部装备状态仍封顶且没有消耗次数。
3. 在基地对准训练靶使用主 / 副武器；命中反馈正常，训练靶不会死亡，弹药不减少。
4. 未接受任务时靠近飞船不能出发；接受后进入舱内自动关闭并出发。
5. 抵达洞穴后可采矿、拾取、交存、遭遇波次并完成主目标；基地设备命令不再生效。
6. 交齐 200 晶矿后撤离船自动提前返航；否则地图计时 10:00 自动返场。船抵达后敌人继续增长；全体登舱且目标完成则成功，死亡则失败。
7. 成功 / 失败结果在返程阶段可见；结束后均回到基地指定出生点、恢复装备、保留同一飞船，并要求重新接受下一任务。
8. 测试返回基地后重新出发；第二轮不残留上一轮矿物、敌人、计时、交互或结果状态。

本文件描述目标与当前代码边界，不把尚未运行的验收用例记作通过。
