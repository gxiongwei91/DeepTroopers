# 掘地潜兵 · 本地 TPS 原型

浏览器本地运行的第三人称越肩演示。此目录自带 Three.js r180 ES module，不需安装依赖或联网；授权文本见 `vendor/THREE-LICENSE.txt`。

## Windows 便携版

需要安装 Node.js 与 pnpm；在此目录运行：

```powershell
pnpm install
pnpm build:windows
```

生成的 Windows x64 单文件程序位于 `dist/DeepTroopers-0.1.1-Windows-Portable.exe`。复制该文件到另一台 Windows 电脑后双击即可运行；游戏资源已内置，不需要另开浏览器、启动服务器或保持网络连接。

## 启动

在此目录运行：

```powershell
node server.mjs
```

浏览器打开 `http://127.0.0.1:4173`。

## 操作

- `W A S D` 移动，鼠标移动越肩环视/瞄准，`Shift` 冲刺，`Space` 跳跃。
- 鼠标左键射击/挖掘/使用当前职业工具；`1`–`5` 切换装备；`R` 换弹。
- `E` 在基地操作职业位、简报台和整备库；洞穴中长按交存矿物或领取补给。
- `F` 投照明棒，`G` 使用职业投掷物，`B` 用已交存硝石呼叫补给。
- 进入基地后点击游戏画面捕获鼠标；准星固定在屏幕中心，鼠标控制越肩镜头。`Esc` 释放鼠标，点击游戏画面重新捕获。

## 原型内容

- 四个职业及固定配装、职业工具和专属投掷物；基地任务板显示本局锁定的波次阵容与资源预算，接单后可登舱出发。
- 每局 6–10 个随机房间的连通网络，封堵门可用局部破坏打通。
- 晶矿/硝石账本、掉落与背包、交存、随机抽取的四套敌群方案。
- 九种敌种池，单局限定三种普通、两种精英和固定 Boss；包含攀墙、钻地与飞行行为。
- 30 只起步并逐波加量的虫潮、自动返航和全员登舱起飞；飞船发射/返航具有过场特写。
- 悬浮任务简报按当前波次方案展示 3 普通 + 2 精英 + 固定 Boss；战斗 HUD 显示选中装备资源、手雷数量和当前装备槽。

波次数量按单波总投放量统计并分批刷新，不会在一帧内同时生成整波。健康、伤害、地图种子和波次参数集中在 `src/config.js` 与 `src/game.js`，供后续试玩调节。
