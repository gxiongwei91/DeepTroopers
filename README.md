# 掘地潜兵 Demo 设计与网页原型

此仓库包含项目设计文档和可在本地浏览器运行的 TPS 越肩原型。

## 启动网页原型

在 `client` 目录运行：

```powershell
node server.mjs
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173/)。不需要安装 npm 依赖或联网下载运行时资源。

## 操作

- `W A S D` 移动，鼠标环视/瞄准，鼠标左键射击或挖掘。
- `1`–`5` 切换当前职业装备，`R` 换弹，`E` 使用附近设备/交存。
- `F` 照明，`G` 使用投掷物，`B` 用已交存硝石呼叫补给，`Space` 跳跃。
- `Esc` 释放鼠标；点击游戏窗口恢复控制。
